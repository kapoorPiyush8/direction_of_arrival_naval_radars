Direction of Arrival in Naval Radars:

This repository contains implementations of direction-of-arrival (DOA) algorithms for naval radar systems. The goal is to build a practical, research‑oriented toolkit that demonstrates end‑to‑end radar signal processing in maritime environments.

Current Release
MUSIC (Multiple Signal Classification)  
Super‑resolution DOA estimation algorithm for target detection.
Demonstrates how to separate signal and noise subspaces using eigen‑decomposition and identify target angles with sharp pseudo‑spectrum peaks.
